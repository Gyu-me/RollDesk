# Roadmap

- **P0 — Foundation**: 개발환경, 디자인 토큰, 테스트, 문서 구성.
- **P1 — Scenario model**: Scenario와 ScriptLine 모델 및 안전한 로컬 저장.
- **P2 — Editor workflow**: 붙여넣기, 구조화, 태그와 스타일 편집.
- **P3 — Macro and routing**: MacroTemplate, UserMacro, Branch, Route 관리.
- **P4 — Session runner**: 플랫폼별 Transformer와 실제 세션 실행 흐름.
- **P5 — Connected product**: 계정, 동기화, 라이브러리, 일정, 커뮤니티 확장.
